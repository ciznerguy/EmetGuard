המזהה (Id) משותף לכל טבלה, ולכן מגדירים אותו פעם אחת במחלקת בסיס

למה שאילתה עם פרמטרים?

המשתמש מקליד בשם המשתמש: ' OR '1'='1

✗ חיבור מחרוזות 
sql = "... WHERE Username = '" + username + "'";
השאילתה שנשלחת:
... WHERE Username = '' OR '1'='1'
'1'='1' תמיד נכון: מתקבלות כל השורות. הקלט הפך לחלק מהקוד.
✓ פרמטר 
sql = "... WHERE Username = @Username";
command.Parameters.AddWithValue("@Username", username);
MySQL מקבל את הערך בנפרד:
@Username = "' OR '1'='1" ← just text
מחפשים משתמש ששמו בדיוק הטקסט הזה. אין כזה, ולכן אין תוצאה.
לזכור: ההתקפה נקראת SQL Injection. פרמטרים מונעים אותה, כי הערך אף פעם לא הופך לחלק מהשאילתה.
