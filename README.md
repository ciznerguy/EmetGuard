# EmetGuard: פרויקט דוגמה

פלטפורמה לשיעור אינטראקטיבי בזיהוי פייק ניוז. המורה מציג ידיעה, התלמידים מצביעים "אמת" או "פייק" בזמן אמת, ובסוף הדיון המורה מפרסם את המסקנה.

הפרויקט בנוי בארבע שכבות: Model, DAL, API ו-View, עם Blazor Server, ASP.NET Core Web API ו-MySQL.
